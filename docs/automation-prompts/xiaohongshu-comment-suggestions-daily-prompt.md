# 每日自动化 Prompt：小红书大 V 评论建议

> 用途：每日检索目标创作者近期公开笔记，生成真实、有针对性的评论草稿，供本人筛选使用。
> 调度建议：每日 1 次；仅检索与建议，不自动点赞、评论、关注、私信或发布。
> 配套：[../selection-to-post-workflow.md](../selection-to-post-workflow.md)

---

请在每天执行时，检索以下创作者最近发布的公开内容，并为我的账号「演讲金句切片厂」提供有针对性的评论建议。

【执行前置检查】

1. 小红书站内搜索必须先确认小红书 MCP 服务可用；服务可用时，先检查登录状态，再继续检索。
2. 如果小红书 MCP 服务未连接，明确提示“请先运行 `/setup-xhs-mcp` 完成部署和配置”，本次停止小红书站内检索；不得用浏览器自动化、网页抓取或其他工具绕过/替代小红书 MCP。
3. 仅检索公开可访问的内容，不尝试访问私密、付费、受限或需绕过访问控制的内容。

【目标创作者】

优先检索这些 AI、科技和知识类创作者：数字生命卡兹克、AI产品黄叔、momo子讲AI、跟着阿亮学AI、karminski-牙医、Simon_阿文、图灵的猫、硅基实验室、成前AI、小林coding。
也可以补充近期发布了 AI、科技、创业者访谈或公开演讲相关内容的同类型创作者，但请说明补充原因，不要只因为粉丝多就纳入。

【检索范围】

1. 优先检索小红书公开笔记；必要时参考创作者在抖音、B站、视频号或其他公开平台发布的同一内容。
2. 优先选取最近 72 小时发布、评论区仍有讨论的内容。
3. 内容主题优先级：AI/科技人物访谈、公开演讲、AI coding、具身智能、AI 产品与真实应用。
4. 只推荐能打开并核对内容的帖子。每条都提供原始链接、作者、标题和发布时间；无法确认的字段标注“未核实”，不要猜测或补造。
5. 排除与「演讲金句切片厂」定位明显无关的内容、纯广告、抽奖引流、重复搬运，以及评论区已经停止互动的旧内容。
6. 如果最近没有合适的新内容，请明确写“本次没有符合条件的帖子”，不要用不相关内容凑数。

【筛选与排序】

从检索结果中选出最多 5 条，按以下标准综合排序：

- 与公开演讲、人物访谈、AI/科技主题的相关度；
- 发布时间的新鲜度；
- 评论区是否有真实讨论、是否适合补充观点；
- 我能否基于已核实的信息写出有价值的评论。

【每条结果请按此格式输出】

1. 作者 / 平台 / 帖子标题
2. 发布时间 / 原帖链接
3. 内容在讲什么：用 1-2 句话概括
4. 为什么值得参与评论：指出具体讨论点，不要只写“流量大”
5. 建议评论：给出 2 个版本
   - A版：补充信息或观点，简短、有实质内容
   - B版：针对原帖观点提出自然的问题，邀请讨论
6. 评论依据：说明建议中的事实、观点或引语来自帖子哪部分；无法核实的内容不要放进评论
7. 参与优先级：高 / 中 / 低，并用一句话说明

【评论写作要求】

- 评论要针对原帖具体内容，像真实读者交流，不写通用夸赞。
- 先回应作者观点，再补充一个有用的信息、不同角度或具体问题。
- 语气自然、克制、有礼貌；建议控制在 30-80 字。
- 不要写“互关互赞”“求关注”“来我主页看”等导流话术，不在评论里重复账号简介。
- 不要冒充亲历者，不得捏造数据、引用、时间点或个人经历。
- 不要复制其他高赞评论，也不要在同一作者的多条帖子下重复发相似评论。
- 如果没有足够信息写出具体评论，请标注“暂不建议评论”，并说明缺少什么信息。

【重要】

只提供检索结果和评论草稿，不要替我点赞、评论、关注、私信或发布。最终评论由我本人选择并确认。
