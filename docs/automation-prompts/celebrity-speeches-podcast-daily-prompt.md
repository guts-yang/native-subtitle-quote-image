# 每日自动化 Prompt：名人演讲与播客推荐（AI 名人长内容 → 金句长图 + 小红书文案）

> 用途：每日定时任务，检索近 1-3 天 AI 名人演讲/播客，产出 3 组字幕金句长图 + 1 篇可直接发布的小红书文案；纯音频播客降级为文字要点。
> 调度建议：每日 1 次（如 09:00）。执行时以本文件正文为任务指令全文。
> 配套：[../selection-to-post-workflow.md](../selection-to-post-workflow.md) ｜ [../youtube-source-cookbook.md](../youtube-source-cookbook.md)

---

每日检索近 1-3 天 AI 领域名人（如 Sam Altman、黄仁勋、Demis Hassabis、李飞飞、LeCun、马斯克，以及国内王兴兴、杨植麟等）的公开演讲、播客访谈、发布会 Keynote、对话节目等长内容，来源覆盖 YouTube、TED、主要播客平台（如小宇宙）与官方发布会回放，侧重 AI coding 与具身智能方向。

第一步：筛选 3-5 条有价值的内容，每条输出：1）基本信息：讲者、场合、时长、完整链接；2）核心观点：2-3 条要点或金句；3）值得关注的原因。结合 memory.md 中之前推送过的内容查重：同一演讲/单集不重复推送，同一人物 7 天内不重复；若当天无新演讲，改推近期未推送过的高质量播客单集。

第二步：挑选其中最具传播力且有视频画面的 1 个内容，获取视频与带时间戳的文字稿，选出 3 组 4-5 句/组语义递进的金句，中文翻译须核对含义、人名与数字。使用 native-subtitle-quote-image 技能制作字幕金句长图：3:4 竖版、1440×1920，第一帧为主画面、其余为字幕条，画面为真实视频帧。若原画面自带中文烧录字幕则保留原字幕不重绘（原生字幕模式）；否则将已核对中文台词后期绘制到真实帧上（脚本字幕模式），交付时注明所用模式。生成 1-3 张/组，台词较多时拆多张，不压缩字幕条，生成 3 组长图。

第三步：逐张质检：字幕完整稳定无重复、无切脸、无播放器 UI 残留、手机缩略图可读；发现问题的帧仅移动时间点（0.3-1.5 秒）或调整字幕区域后重渲，最多三轮。

第四步：撰写一篇小红书文案：吸引点击的标题（18-20 字）、正文要点提炼、3-5 个相关话题标签，语气亲切有干货感，300 字左右可直接发布。文案与图片中均不得出现任何账号 IP 名称或系列编号。若选中内容为纯音频播客（无视频画面），降级输出：文字要点 + 金句摘录 + 收听链接，并说明无法生成长图的原因。

> 技能位置：`~\skills\native-subtitle-quote-image\SKILL.md`，或本仓库 `skills/native-subtitle-quote-image/SKILL.md`（首次执行时若本地未部署，先 clone 本仓库到本地进行维护）。
