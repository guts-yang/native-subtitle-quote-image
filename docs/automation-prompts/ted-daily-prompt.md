# 每日自动化 Prompt：TED 推荐（TED 演讲 → 金句长图 + 小红书文案）

> 用途：每日定时任务，从 TED 频道选 1 个优质演讲，产出 3 组字幕金句长图 + 1 篇可直接发布的小红书文案。
> 调度建议：每日 1 次（如 09:00）。执行时以本文件正文（下方引用块外）为任务指令全文。
> 配套：[../selection-to-post-workflow.md](../selection-to-post-workflow.md) ｜ [../youtube-source-cookbook.md](../youtube-source-cookbook.md)

---

请从 TED 频道（https://www.youtube.com/ted）筛选最新发布的 1-2 个优质演讲视频，结合 memory.md 中之前推送过的内容查重，同一演讲不重复推送。

第一步：对每个候选视频输出：1）基本信息：标题、讲者、时长、完整视频链接；2）推荐理由：适合人群与值得观看的原因；3）内容讲解：演讲主题、关键观点与代表性金句。

第二步：挑选其中最具传播力的 1 个视频，获取视频文件与带时间戳的文字稿，选出三组 4-5 句/组语义递进、适合传播的金句，中文翻译须核对含义、人名与数字，不得编造。随后使用 native-subtitle-quote-image 技能制作字幕金句长图：3:4 竖版、1440×1920，第一帧为表情、手势、构图俱佳的主画面，其余为字幕条；画面使用真实视频帧，字幕为后期绘制的已核对中文台词（脚本字幕模式），交付时明确标注"脚本字幕"。台词较多时拆成多张图，不压缩字幕条，总共生成3组长图。

第三步：逐张质检：字幕完整稳定无重复、无切脸、无播放器 UI 残留、手机缩略图下文字可读；发现问题的帧仅移动时间点（0.3-1.5 秒）或调整字幕区域后重渲，最多三轮。

第四步：为该视频撰写一篇小红书文案：含吸引点击的标题（最好包含TED这个关键词，必须在 20 字以内）、正文要点提炼、3-5 个相关话题标签，语气亲切且有干货感，控制在 300 字左右，可直接复制发布。文案与图片中均不得出现任何账号 IP 名称或系列编号。若无法获取视频内容，说明限制并给出替代方案。

> 技能位置：`~\skills\native-subtitle-quote-image\SKILL.md`，或本仓库 `skills/native-subtitle-quote-image/SKILL.md`（首次执行时若本地未部署，先 clone 本仓库到本地进行维护）。
